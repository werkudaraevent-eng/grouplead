# Superseded

The guidance that used to live here is replaced by [`/AGENTS.md`](../AGENTS.md)
at the repository root.

It was written when this repository held LeadEngine alone, and it had gone stale
in ways that actively misled: it described a `src/` directory that neither app
has, named React 18 and Next.js 14 when both apps run React 19 and Next.js 16,
and said nothing about Sales Activity, about where migrations live, or about how
work is published. An agent that trusted it went looking for files that do not
exist.

`AGENTS.md` is the single file to read, and the single file to update when a
working rule changes. Its history is in git if you need what this one said.
