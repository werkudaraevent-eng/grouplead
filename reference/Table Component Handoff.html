05 — Agent Prompt (Copy & Paste ke IDE)
Prompt siap pakai untuk Claude, Cursor, Copilot, atau agent IDE lainnya. Ganti bagian dalam [...] sesuai kebutuhan.
Buat komponen data table dengan spec berikut:

STACK: [React / Vue / HTML+CSS — pilih salah satu]

DESAIN (wajib diikuti persis):
- Font: Plus Jakarta Sans (Google Fonts), fallback sans-serif
- Outer container: border-radius 12px, border 1px solid #E5E7EB, overflow hidden
- Toolbar: padding 12px 16px, flex row, gap 9px, border-bottom 1px #E5E7EB
  - Search input: bg #F3F4F6, border 1.5px solid #E5E7EB, border-radius 8px,
    padding 6px 12px, icon di kiri, placeholder warna #9CA3AF
  - Action buttons di kanan (Columns, Export, Import, Add):
    border 1.5px solid #E5E7EB, border-radius 8px, font-size 12.5px, font-weight 600
  - Primary button (Add): bg #0EA5E9, text white, hover bg #0284C7

- Header (TH):
  - font-size 11px, font-weight 700, text-transform uppercase, letter-spacing .05em
  - color #6B7280, background #FAFAFA
  - border-bottom 1.5px solid #E5E7EB (lebih tebal dari row separator)
  - padding 10px 16px, cursor pointer, user-select none
  - hover: background #F3F4F6, color #111827
  - sorted state: color #0EA5E9

- Data cells (TD):
  - font-size 13px, padding 10px 16px, color #111827
  - border-bottom 1px solid #F3F4F6 (BUKAN #E5E7EB — harus lebih subtle)
  - last row: border-bottom none

- Row hover: background #F0F9FF (semua TD di row itu)
- Transition pada background: .1s ease

- Avatar chip: 26x26px, border-radius 50%, font-size 10px, font-weight 800,
  warna bg per user (buat mapping warna dari nama/initial), text white

- Sector/type badge:
  - Public: bg #E0F2FE, color #0EA5E9
  - Private: bg #F3F4F6, color #374151
  - padding 2px 8px, border-radius 6px (BUKAN pill), font-size 11.5px, font-weight 600

- Email: warna accent #0EA5E9, font-size 12px
- Phone: font-variant-numeric tabular-nums, font-size 12.5px
- Muted/empty cells: warna #9CA3AF, tampilkan "—"

- Footer:
  - padding 11px 16px, flex space-between, font-size 12.5px, color #6B7280
  - border-top 1px solid #E5E7EB, background #FAFAFA
  - Kiri: "Showing X–Y of Z entries" (X-Y dan Z dalam tag strong, color #111827)
  - Kanan: "Rows per page" select + Previous/Next buttons
  - Pagination buttons: border 1.5px solid #E5E7EB, border-radius 6px,
    font-size 12px, font-weight 600, disabled state: opacity .4

KOLOM untuk Companies table:
NO. | Owner (avatar+nama) | Company Name (avatar+nama bold) | Sector (badge) | Line Industry | Phone | ··· (action menu)

KOLOM untuk Contacts table:
NO. | Owner (avatar+nama) | Contact Name (avatar+nama bold) | Company | Job Title | Email (accent color) | Phone (monospace) | ··· (action menu)

BEHAVIOR:
- Search: filter real-time dari sisi client
- Sort: klik TH toggle asc/desc, tampilkan ↕ di header
- Pagination: client-side, 20 rows default
- Row click: emit event / callback ke parent
- Action button (···): dropdown menu (Edit, Delete)

DATA: [Ganti dengan struktur data Anda, atau terima sebagai props/API]

JANGAN:
- Jangan gunakan library tabel pihak ketiga (DataTables, AG Grid, etc.)
- Jangan tambahkan shadow pada individual rows
- Jangan gunakan border-radius pada TH/TD
- Jangan hard-code warna — gunakan CSS variables
06 — Quick Reference Card
✅ Do
  • ✓ Row separator #F3F4F6 (sangat subtle)
  • ✓ Header border 1.5px (lebih tebal)
  • ✓ Hover tint dari accent color
  • ✓ Avatar warna unik per user
  • ✓ Phone number = tabular-nums
  • ✓ Sticky header saat scroll
  • ✓ Footer background match header
  • ✓ TH uppercase + letter-spacing
❌ Don't
  • ✗ Jangan tampilkan nomor HP sebagai scientific notation
  • ✗ Jangan pakai border pada semua sisi TD
  • ✗ Jangan alternating row colors (zebra stripe)
  • ✗ Jangan shadow per row
  • ✗ Jangan hardcode warna avatar
  • ✗ Jangan pill (radius 20px) untuk sector badge
  • ✗ Jangan font-size < 11px di mana pun
  • ✗ Jangan semua kolom lebar sama
