Alur Admin

Akses penuh

Bisa mengelola seluruh sistem: data, target, pengguna, dan hak akses.

  • Masuk
    • Lupa kata sandi

      Reset via email → buat sandi baru.

    • Beranda / Dashboard

      Ringkasan seluruh unit bisnis: target, pencapaian, grafik.

      • Pipeline

        Lihat, tambah, ubah, hapus lead. Rincian & cetak PDF.

      • Perusahaan

        Kelola perusahaan pelanggan + dokumen.

      • Kontak

        Kelola narahubung + dokumen.

      • Riwayat

        Catatan semua aktivitas.

      • Pengaturan

        Hanya Admin.

        • Kolom & tahap

          Isian data, dropdown, tahap Pipeline.

        • Target

          Periode & aturan target.

        • Pengguna & unit bisnis

          Tim, jabatan, kuota, struktur grup.

        • Hak akses

          Siapa boleh lihat / ubah apa.

Alur Sales

Menu harian saja

Fokus pekerjaan harian. Menu Pengaturan tidak muncul, dan tidak bisa menghapus data.

  • Masuk
    • Lupa kata sandi

      Reset via email → buat sandi baru.

    • Beranda / Dashboard

      Ringkasan data perusahaannya saja: target & pencapaian.

      • Pipeline

        Lihat, tambah, ubah lead. Tidak bisa hapus. Rincian & cetak.

      • Perusahaan

        Lihat perusahaan pelanggan + dokumen.

      • Kontak

        Lihat narahubung + dokumen.

      • Riwayat

        Catatan aktivitas.

      • Profil saya

        Ubah data akun sendiri (lewat foto profil).
